# Фильтр объявлений Avito
Вайбкод-юзерскрипт, в котором всё написало AI, чем я и горжусь. Скрипт добавляет на сайте avito.ru меню, которое даёт возможность скрыть объявления, которые "забронированы" и которые "просмотрены", а также те, где отключена Авито-доставка.

# Чёрный список
В скрипте реализован чёрный список. Рядом с каждым ником пользователя теперь есть кнопка "В ЧС", которая добавит его в "Чёрный список" и вы больше его не увидете в выдаче. Удалить пользователя из ЧС тоже просто - нажмите Х рядом с его ником в виджете скрипта.
Чёрный список не работает на главной странице, он предназначен только для страниц поиска. Список можно экспортировать и импортировать.

# Установка
Установите расширение [TAMPERMONKEY](https://www.tampermonkey.net/) на Ваш браузер, после чего [УСТАНОВИТЕ](https://raw.githubusercontent.com/cjblackace/avito-ad-filter/refs/heads/main/avito-ad-filter.user.js) скрипт. Всем удачных покупок!
